# Week 11 procedure — persistence with files

1. Prepare a CSV header and three workout rows.
2. Save the rows to `fitness-sessions.csv` in the project week folder.
3. Read the saved file back into memory.
4. Split each stored row and total its minute column.
5. Print the count and total read from the persisted file.

Compile and run with `javac FitnessFileStore.java` followed by `java FitnessFileStore`.
