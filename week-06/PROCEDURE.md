# Week 6 procedure — arrays and searching

1. Store weekday names and workout minutes in matching arrays.
2. Use one loop to total the minutes.
3. Use `mostActiveDayIndex` to locate the largest value.
4. Use `indexOf` to find a named day safely.
5. Print the total, peak day and search result.

Compile and run with `javac WorkoutArrayTracker.java` followed by `java WorkoutArrayTracker`.
