# Week 4 procedure — loop-driven workout menu

1. Define two sample workout activities and their durations.
2. Display the three menu options a learner would see in the console app.
3. Use a `while` loop to record each activity.
4. Use a decision to compare each duration against the daily goal.
5. Print the number of processed sessions.

Compile and run with `javac FitnessMenu.java` followed by `java FitnessMenu`.
