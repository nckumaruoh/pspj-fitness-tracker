# Week 5 procedure — reusable methods

1. Move the weekly-total calculation into `weeklyTotal`.
2. Add a reusable calorie estimate method using six calories per recorded minute.
3. Add a goal-status method that returns a learner-friendly result.
4. Call the methods from `main` using the same five-day sample used in Week 3.

Compile and run with `javac WorkoutService.java` followed by `java WorkoutService`.
