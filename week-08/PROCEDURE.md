# Week 8 procedure — recursive streak calculation

1. Store seven daily minute values.
2. Pass the current array index, current streak and best streak into a recursive method.
3. Increase the current streak only when the day meets the 30-minute goal.
4. Reset the current streak when the goal is missed.
5. Return the best value after the final array position.

Compile and run with `javac StreakCalculator.java` followed by `java StreakCalculator`.
